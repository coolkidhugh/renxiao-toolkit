# 企业人效怎么计算

## 定义

**人效**（人力资源效能 / 劳动生产率相关口径）指单位人力投入所对应的产出或效益。企业常用一组可量化指标，把「人」与「结果」对齐，用于经营回顾、编制规划与人工成本管控。

人效不是单一数字，而是一套口径一致、可纵向对比的指标组合。计算前须先约定：统计周期、人数口径（期末人数 / 平均人数）、产出口径（营收 / 产值 / 利润 / 毛利）以及是否含外包与兼职。

## 公式 / 步骤

### 常用指标公式

| 指标 | 公式 | 说明 |
|---|---|---|
| 人均营收 | 营业收入 ÷ 平均人数 | 看单位人力创造的收入规模 |
| 人均产值 | 产值（或完工产值）÷ 平均人数 | 制造、工程等有「产值」口径时常用 |
| 人均利润 | 净利润（或营业利润）÷ 平均人数 | 看单位人力创造的利润 |
| 人工成本投产比 | 营业收入（或产值）÷ 人工成本总额 | 看每 1 元人工成本对应多少产出 |
| 人工成本率 | 人工成本总额 ÷ 营业收入 × 100% | 与投产比互为倒数关系，便于对标 |
| 人均人工成本 | 人工成本总额 ÷ 平均人数 | 用于编制与带宽校验 |

**平均人数**常用算法（选一种并固定）：

- 月度：`(月初人数 + 月末人数) ÷ 2`，再对全年取平均；或
- 全年：各月平均人数之和 ÷ 12。

**人工成本**通常包括：工资、奖金、津贴、社保公积金企业部分、福利、辞退补偿等。是否含劳务派遣/外包费用，须在口径说明中写清。

### 计算步骤

1. **定口径**：周期、人数、产出、人工成本范围写成一页「口径说明」。
2. **取数**：财务取营收/利润/人工成本；HR 取人数与编制变动。
3. **算指标**：按上表计算，保留与经营报表一致的小数位。
4. **拆维**：按事业部、职族、职级或城市拆开，避免「全公司一个平均数」掩盖结构问题。
5. **对比**：与自身历史同期、内部标杆单元对比；外部对标仅在口径可比时使用。
6. **解读**：区分「人数变了」「单价/结构变了」「业务结构变了」三种驱动，再谈动作。

## 适用场景

- 季度/年度经营会需要「人效」一页纸时
- 编制与招聘计划论证（增人是否带来产出）
- 人工成本预算与调薪包测算
- 业务线或分子公司横向对比
- 组织精简或业务收缩后的效能复盘

不适合单独作为裁员或否决调薪的唯一依据；须结合业务阶段、产能爬坡、战略投入期等因素。

## 企业人效一般看哪几个指标？

多数企业先看 **人均营收（或人均产值）**、**人工成本率 / 投产比**、**人均利润**。再按行业补 1～2 个过程指标（如人均产能、人单比）。指标宜少而稳，口径三年内尽量不改。

## 人均营收和人均利润哪个更重要？

取决于阶段。成长期、扩张期常更关注人均营收与市场份额相关产出；盈利压力大或成熟期更关注人均利润与人工成本率。两者一起看，避免只推收入不看利润，或只压成本伤及增长。

## 人数口径用期末人数还是平均人数？

算「期间效能」用 **平均人数** 更稳，减少月末突击入职/离职的扭曲。编制与时点快照可用期末人数，但须在报告中标明，勿与期间指标混用。

## 外包和劳务派遣算进人效吗？

两种常见做法：  
（1）人数与成本都不含外包，人效只反映合同制员工；  
（2）把外包费用计入人工成本（或「广义人力成本」），人数按「等同全职」折算或不折算但成本全计。  
关键是 **人数与成本同进同出**，并在口径说明中固定一种。

## 人效算出来以后怎么用？

建议顺序：口径确认 → 趋势与结构拆解 → 与业务动作挂钩（编制、调薪、组织、流程）→ 设下一周期监测指标。避免只做排名通报；人效是诊断输入，不是处罚标签。
