# 薪酬带宽怎么设计

## 定义

**薪酬带宽**（pay range / salary band）是某一职级或职等对应的薪酬允许区间，通常用 **下限、中位值（或中点）、上限** 表示。带宽把「外部竞争力」与「内部相对公平」落成可执行的区间规则，用于定薪、调薪、晋升与录用谈薪。

相关概念：

- **薪级 / 职级**：纵向等级（如 P1–P8、M1–M4）。
- **带宽宽度**：`(上限 − 下限) ÷ 中位值`，或 `(上限 − 下限) ÷ 下限`，口径需统一。
- **级差**：相邻职级中位值之比或之差。
- **重叠度**：相邻带宽交叉的程度；重叠过大易导致「晋升不涨薪感」，过小则晋升压力大。

## 公式 / 步骤

### 结构要素

对每一职级定义：

| 要素 | 含义 |
|---|---|
| 中位值（Mid） | 该职级市场对标或内部策略锚点 |
| 下限（Min） | 通常可设为 Mid × (1 − 宽度/2 的某种形式)，或 Mid ÷ (1 + 半宽) |
| 上限（Max） | Mid × (1 + 半宽) 等，与 Min 对称或按策略不对称 |
| 宽度 | 如 40%、50%、60% 等，高职级/专业职往往更宽 |

示例关系（对称宽度 \(w\)，以中位为中心的一种常见写法）：

- \(\mathrm{Min} = \mathrm{Mid} \div (1 + w/2)\) 的变体，或直接规定 \(\mathrm{Min} = \mathrm{Mid} \times (1 - w/2)\)、\(\mathrm{Max} = \mathrm{Mid} \times (1 + w/2)\)（当 \(w\) 为相对中位的总宽度时需事先定义清楚）。

实务中更常见的是：**先定 Mid 与目标宽度，再反算 Min/Max，并做整数圆整**。重要的是全公司共用同一套定义，写进薪酬制度附录。

### 设计步骤

1. **职级体系就绪**：有清晰的职级定义与晋级标准，否则带宽无「挂」处。
2. **薪酬策略**：领先 / 跟随 / 滞后市场；是否分城市、分序列（专业/管理/销售）不同策略。
3. **市场数据**：选用可靠薪酬调查或公开渠道，注意岗位匹配度、分位值（如 50 分位、75 分位）与生效年份。
4. **定中位值曲线**：各职级 Mid 形成平滑级差（常见级差随职级升高而变化，需符合内部支付能力）。
5. **定宽度与重叠**：基层可相对窄、标准清晰；专家与管理级可更宽以容纳能力差异。检查相邻级重叠是否可接受。
6. **固浮比与津贴**：带宽通常管「现金性固定+浮动的政策范围」或只管基本工资——须在制度中写明范围。
7. **圆整与落地规则**：入职工资落点、试用期、调薪不突破上限的例外审批、晋升进带宽的规则。
8. **测算成本**：用现有人员 sal 模拟套入，看涨薪成本与异常点（过高/过低）。
9. **沟通与版本管理**：向管理者培训「如何在带宽内谈薪」；文件版本号与生效日。

### 落点与调薪（常用规则思路）

- **新人定薪**：按匹配度落在 Min～Mid 或 Mid 附近；稀缺人才经审批可靠近上限。
- **绩效调薪**：绩效高且 sal 偏低（如低于 Mid）优先补距；已近上限则更多用奖金或晋升解决。
- **晋升**：进入新职级带宽后，按规则一次调整到新 Min 以上或目标分位。

## 适用场景

- 中小企业从「一岗一价、负责人拍板」走向制度化
- 多城市、多序列扩张，需要统一谈薪语言
- 并购或架构调整后薪酬体系整合
- 调薪季、校园招聘季前的政策准备

不适用：在职级混乱、岗位描述缺失时强行上带宽（会变成数字游戏）。也不应用带宽替代对贡献的绩效讨论。

## 薪酬带宽宽度一般设多少？

常见实践是按职级分层：执行层相对窄、专业骨干与管理层更宽，以便容纳能力与稀缺性差异。具体比例应结合市场数据离散度、内部现有 sal 分布与晋升节奏，没有放之四海的固定数。设计时用现有人员做套算，比照搬「标准宽度」更重要。

## 中位值一定要等于市场 50 分位吗？

不一定。中位值是**公司策略锚点**：可以整体跟随 50 分位，也可以对关键职族用更高分位、对成本敏感职族用更低分位。关键是策略写清楚，并与支付能力、招聘难度一致。

## 带宽重叠是好事还是坏事？

适度重叠是常见的：允许高绩效低职级与低绩效高职级在现金上有交叉，减少「为了涨薪硬晋升」。重叠过大则职级激励弱；过小则晋升必须大幅跳薪，成本陡。用重叠度指标检查，并配套晋级标准。

## 没有买薪酬报告能不能做带宽？

可以先做「内部相对带宽」：按职级梳理现有薪酬分布，用中位数作临时 Mid，再设宽度与调薪规则；同时用招聘反馈与离职原因作外部压力的定性校准。有预算后再引入正规调研数据修正 Mid。避免长期完全拍脑袋定薪。

## 销售提成制岗位怎么进带宽？

常见做法：对**基本工资（或保证收入）**设带宽；提成/佣金另用业绩制度。总现金竞争力用「目标总现金（OTC）」对标市场。勿把高波动的提成硬塞进同一套固定薪带宽而不加说明。
