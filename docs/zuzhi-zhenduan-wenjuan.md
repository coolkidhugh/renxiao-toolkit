# 组织诊断一般怎么做

## 定义

**组织诊断**是系统收集组织在战略落地、结构、流程、人才、文化与领导力等方面的信息，识别优势与瓶颈，并提出可执行改进方向的过程。它不是一次性「做问卷」，而是「问题定义 → 取证 → 归因 → 行动设计」的闭环。

常见输入包括：经营与人效数据、组织架构与编制、岗位与职级、流程与权责、员工问卷、管理者访谈、焦点小组等。输出通常是诊断结论、优先级议题与改进路线图。

## 公式 / 步骤

组织诊断没有单一数学公式，但有可复用的步骤骨架：

### 1. 澄清诊断目的与边界

- 要回答的业务问题是什么？（例如：增长乏力是否与组织协同有关、并购后整合卡点、人效下滑归因）
- 诊断范围：全公司 / 某事业部 / 某职能
- 不做什么：本次不评估个人绩效、不处理劳动争议个案（除非另行约定）

### 2. 设计证据组合

| 证据类型 | 典型用途 |
|---|---|
| 经营与人效数据 | 客观结果与趋势 |
| 架构、编制、汇报线 | 结构与跨度是否匹配战略 |
| 流程与 RACI | 决策慢、重复、真空 |
| 员工问卷 | 感知、氛围、管理行为频率 |
| 管理者访谈 | 因果解释与政治/信息盲区 |
| 焦点小组 | 跨部门协同卡点 |

原则：**数据看结果，问卷看分布，访谈看机制**。三者交叉验证，避免只信问卷均值。

### 3. 问卷设计要点（若使用）

- 维度示例（可按目的裁剪）：战略清晰度、目标与绩效、协作与流程、授权与决策、人才发展、激励公平感、直接上级管理行为、变革准备度。
- 题量控制：全员卷通常宜短；管理者可加开放题。
- 量表一致（如 1–5），并预留「不适用」。
- 人口学字段只收分析必需项，注意匿名与最小必要原则。
- 先小样本试填，改歧义题再全员发放。

### 4. 实施与分析

1. 沟通目的、保密与用途，降低防卫。
2. 回收后看：应答率、维度均分、部门/职级差异、高低分题项、开放题主题编码。
3. 访谈按议题提纲进行，对问卷异常点追问「机制」而非「谁对谁错」。
4. 形成议题清单：每个议题写清「现象—证据—可能根因—建议动作—责任与节奏」。

### 5. 反馈与落地

- 向发起人与核心管理层反馈；必要时做脱敏后的组织反馈。
- 选出 3～5 个优先行动，设责任人与检查点。
- 约定复测或脉搏调查的时间，验证是否改善。

## 适用场景

- 战略调整、业务重组、并购整合前后
- 人效或业绩异常，需要区分「市场/产品」与「组织机制」
- 组织扩编后出现协同乱、决策慢
- 文化或敬业度长期偏低，需定位管理行为与制度问题
- 引入薪酬绩效或人效项目前的基线摸底

不适合：用诊断替代日常管理对话；或在未澄清目的时「为了做而做问卷」。

## 组织诊断一定要做全员问卷吗？

不一定。小范围、议题清晰时，深度访谈 + 数据复盘可能更高效。全员问卷适合需要看分布、对比部门/职级、建立基线或复测时。关键是证据能否支撑结论，而不是形式是否「完整」。

## 组织诊断问卷一般包含哪些维度？

常见维度包括：战略与目标传递、组织结构与权责、流程与协作、领导与授权、绩效与激励感知、人才发展、文化与价值观践行、变革与创新氛围。按诊断目的删减，避免「大而全却无法行动」。

## 问卷结果和访谈结论冲突怎么办？

以交叉验证为准：看是样本偏差、题项歧义，还是「公开表达」与「私下机制」不一致。冲突本身往往是重要发现（例如制度写着授权、实际层层加签）。结论应写清证据张力，而不是强行平均。

## 诊断报告交给谁、怎么避免变成整人工具？

事先约定：报告服务组织改进，对个人评价另走绩效流程；问卷匿名规则与最小可识别群体（如某组少于 N 人不出分）；管理层反馈聚焦机制与行动。发起人应在开场沟通中公开这些边界。

## 做完一次诊断多久适合再做？

大诊断常见按年或重大变革节点；脉搏/专题卷可按季度。复测题项尽量保持稳定，才能比趋势。若组织动作尚未落地，过早复测意义有限。
